# Задача
Сделать главную страницу сервиса Froggion целиком. Её центр — живая 3D-сцена: на парящем острове из майнкрафтовских блоков четыре бота повторяют движения из записи Replay Mod. Один бьёт криперов, второй рыбачит, третий копает, четвёртый сажает и собирает урожай. Это не видео и не симуляция: из реплея извлекается лента событий, а браузер проигрывает её на three.js. При наведении на бота над ним всплывает карточка с его именем и описанием, и из неё можно скачать скин бота.

# Карточка бота
- **При наведении** на бота он подсвечивается контуром, а над его головой всплывает карточка. Бот определяется лучом из курсора по его модели.
- **Положение карточки:** она привязана к экранной точке над головой бота и следует за ним и за камерой. У края экрана карточка сдвигается внутрь.
- **Содержимое:**
  - имя (заголовок);
  - описание;
  - кнопка «Скачать скин»: скачивает PNG бота из `public/skins/`, имя файла вида `froggion-miner-skin.png`;
  - ссылка «Подробнее», которая прокручивает страницу к блоку этого бота в секции «Работа ботов».
- **Закрытие:**
  - когда курсор уходит с бота на карточку, она не пропадает (задержка около 300 мс), иначе до кнопки не дотянуться;
  - клик или тап по боту закрепляет карточку;
  - закрывают её клик мимо и Esc.
- **Телефон:** тап по боту открывает карточку, тап мимо закрывает.
- **Клавиатура:** рядом со сценой есть доступный список четырёх ботов (кнопки, видимые при фокусе). Кнопка открывает ту же карточку.
- **Тексты** карточек берутся из `content/*.json`, стиль — как у остальной страницы.

# Техника
- Vite и чистый JS, без UI-фреймворков. Результат — статическая папка `dist/` под nginx.
- Русский — основной язык, английский — на `/en/`. Весь текст лежит в `content/ru.json` и `content/en.json`, я буду править только их.
- Текст должен быть в готовом HTML для SEO, а не вставляться скриптом. Нужны canonical, hreflang, Open Graph и favicon.
- Инструменты подготовки данных (Node ≥20) лежат в `tools/`, их результат коммитится в `public/data/`. Сайт читает только готовые данные.
- Производительность:
  - первый экран грузится быстро даже без 3D: LCP меньше 2.5 с на среднем телефоне;
  - three.js и данные сцены грузятся после первой отрисовки, до этого показывается постер-кадр;
  - один WebGL-холст на страницу; анимация на паузе вне экрана и на скрытой вкладке;
  - плотность пикселей (DPR) не выше 2, на телефонах облегчённый режим;
  - при `prefers-reduced-motion` или без WebGL — постер и обычная прокрутка, а карточки ботов открываются из списка;
  - всё, кроме three.js и скинов, вместе с данными сцены — не больше 300 КБ в gzip.

# Реплей → ленты событий (`tools/replay-to-timeline.js`)
- `.mcpr` — это ZIP с `metaData.json` и `recording.tmcpr`. В tmcpr подряд идут записи `[int32 BE время, мс][int32 BE длина][пакет]`, пакеты clientbound.
- Поток начинается в состоянии login с пакета `success`, после него идёт play.
- Пакеты разбирай через `minecraft-protocol` для версии 1.16.5, свой парсер пакетов не пиши.
- Что извлечь. Имена пакетов сверяй с minecraft-data 1.16.5:
  - игроки и их ники (`player_info`, `named_entity_spawn`);
  - появление и удаление сущностей;
  - позиция, поворот, голова, скорость;
  - взмах руки (`animation`);
  - урон и смерть (`entity_status`);
  - metadata: поза и здоровье;
  - экипировка;
  - поплавок: `fishing_bobber`, владелец указан в данных спавна;
  - изменения блоков (в том числе рост посевов и булыжник генератора) и стадии трещин (`block_break_animation`, их в записях сотни);
  - звуки и частицы всплеска;
  - выпавшие предметы, опыт, подбор (`collect`).
- Ботов сопоставляй с таблицей по нику через UUID из `player_info`, а не по номеру сущности. Посреди записи боты перезаходили: у каждого по два номера сущности.
- Записывающего игрока и всех посторонних выкинь.
- Поворот головы игрока в 1.16 не приходит в пакете появления, только позже, в `entity_head_rotation`, когда голова повернётся. Пока такого пакета не было, бери поворот головы из поворота игрока (`named_entity_spawn` / `entity_look`): у игроков это одно и то же направление взгляда.
- Из двух реплеев для каждого бота выбери дубль с самым чистым циклом, а в отчёте напиши, какой взят.
- Каждый бот крутится по кругу независимо:
  - у каждой станции своя зона со своими сущностями и изменениями блоков;
  - границы цикла у каждого бота свои;
  - конвертер предлагает кандидатов, где поза, позиция и состояние зоны близки к исходным, а я правлю их в `loops.json`;
  - при перезапуске цикла зона возвращается в исходное состояние.
- Выход: позиции и углы по тикам (20 в секунду) с квантованием, события с номером тика; не больше 150 КБ на всю сцену.

# Остров (из реплея)
- Остров уже подготовлен в мире. Вокруг пустота, других построек нет.
- Станции:
  - копание (генератор булыжника) — на юге;
  - рыбалка (пруд) — на западе;
  - криперы (стеклянная клетка) — на севере;
  - ферма (ромб грядок вокруг воды под берёзовой плитой) — на востоке;
  - в центре дерево.
- Блоки бери из чанков в начале записи: `map_chunk` разбирай через `prismarine-chunk` для 1.16.5, дальше применяй изменения блоков из ленты.
- Область острова: X −240…−200, Y 0…40, Z 5…45. Сам остров занимает примерно X −233…−208, Y 0…27, Z 13…36. Всё за пределами области не рисуй.
- Командные блоки, барьеры, невидимые и прочие технические блоки не рисуй, даже если они окажутся на виду.
- Меш:
  - скрытые грани не рисовать, склеивать по атласу текстур;
  - неполные блоки (плиты, ступеньки, люки, таблички, заборы, кнопки, грядки, тропинки и т. п.) — упрощённая своя геометрия по их состоянию;
  - посевы, трава и цветы — как в игре, решётка из плоскостей; у каждой стадии роста посевов своя текстура;
  - стекло — прозрачное, с рамкой из текстуры;
  - вода и лава:
    - стоячая — плоская поверхность с анимированной текстурой;
    - текущая (уровни 1–7) — ниже по высоте уровня;
    - падающая (уровень 8) — вертикальный столб, например водопад с края острова.
- Если чанки из реплея не читаются, остановись и скажи: дам остров отдельным файлом.

# Проигрыватель
- **Гуманоид (боты):**
  - ванильные размеры и точки вращения: голова 8³ на y=24, руки 4×12×4 на (±5, 22), ноги на (±1.9, 12);
  - скин 64×64 с внешним слоем, раздутым на 0.5 и 0.25;
  - у модели `slim` руки шириной 3 пикселя, со своей UV-раскладкой.
- **Крипер:**
  - голова 8×8×8, тело 8×12×4, четыре ноги 4×6×4;
  - текстура 64×32, своя, в духе оригинала;
  - ноги шагают по ванильной формуле четвероногих;
  - крипер сидит в стеклянной трубе, бот бьёт его через щель у ног.
- **Анимация как в ванильном клиенте:** перенеси `HumanoidModel.setupAnim`.
  - шаги ног считаются из скорости;
  - кривая взмаха руки, взмах длится 6 тиков;
  - покачивание рук в покое;
  - голова поворачивается относительно тела, тело догоняет её с запаздыванием;
  - между тиками интерполяция до 60 fps, углы по кратчайшей дуге.
- **Предметы в руке и на земле:** пиксели спрайта 16×16 выдавить в объём толщиной 1/16.
- **Рыбалка:** провисающая леска от кончика удочки к поплавку. Поплавок движется по записи, всплеск рисуется частицами.
- **Копание:** 10 стадий трещин, частицы при разрушении, выпавший предмет подлетает к игроку.
- **Ферма:** посев — росток появляется на грядке; дальше стадии роста по записи; сбор — взмах, частицы, выпавший урожай.
- **Мобы:**
  - при уроне — красный оттенок на 10 тиков и отброс по записи;
  - при смерти — падает набок за 20 тиков, затем облачко.
- **Вид:**
  - текстуры с `NearestFilter`;
  - затенение граней как в игре: верх 1.0, низ 0.5, север/юг 0.8, восток/запад 0.6;
  - никаких PBR-материалов.
- **Над ботами** — ники из таблицы, как в игре. Карточка — см. «Карточка бота».
